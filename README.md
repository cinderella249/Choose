# 選擇障礙 😊

> 有選擇困難嗎？讓扭蛋機和籤筒幫你決定！

一個結合「今天去哪裡」與「今天吃什麼」的 PWA 應用程式。

## 功能

### 🎰 今天去哪裡
- 10 大分類（台南/嘉義/高雄玩透透、動物園、樂園、拜拜...）
- 扭蛋機動畫，滾動 3 次後揭曉結果
- 自訂選項（新增/刪除），支援 Excel / CSV 匯入
- 自動儲存到本機，下次開啟仍保留

### 🍜 今天吃什麼
- 廟宇求籤風格抽籤系統
- 早餐、午餐、晚餐、下午茶、飲料等分類
- 自訂食物選項，支援匯入

## 安裝為 APP

### Android（Chrome）
1. 用 Chrome 開啟網站
2. 點下方「安裝」橫條，或右上角「⋮」→「新增至主畫面」

### iPhone（Safari）
1. 用 Safari 開啟網站
2. 點「分享」按鈕 → 「加入主畫面」

### 電腦（Chrome / Edge）
1. 網址列右側出現安裝圖示，點一下即可

## 上傳到 GitHub Pages

1. 建立新 Repository（設為 Public）
2. 上傳所有檔案（index.html、manifest.json、sw.js、icons/）
3. 進入 Settings → Pages → Deploy from branch → main / root
4. 等 1-2 分鐘，網址為：`https://你的帳號.github.io/repo名稱/`

## 檔案說明

```
index.html          主程式
manifest.json       PWA 設定
sw.js               Service Worker（離線快取）
icons/
  icon-192.png      APP 圖示 192px
  icon-512.png      APP 圖示 512px
  apple-touch-icon.png  iOS 主畫面圖示 180px
  favicon-32.png    瀏覽器分頁圖示
  favicon-16.png    瀏覽器分頁圖示（小）
```
